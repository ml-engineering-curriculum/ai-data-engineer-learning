# Labs for mod-103-web-scale-acquisition-and-curation (Web-Scale Data Acquisition and Curation Pipelines)

Guided, step-by-step hands-on sessions for the module. Each lab has a stated duration, prerequisites, numbered steps with commands or code, expected output, and checkpoints. Labs are *guided practice*; they differ from the module's `exercises/`, which are open-ended design work.

- [Lab 01 — Query the Common Crawl Columnar Index and Emit a Selection Predicate](lab-01-query-the-common-crawl-columnar-index.md) — 60 min. Query the Common Crawl Parquet index (`s3://commoncrawl/cc-index/table/cc-main/warc/`) with DuckDB, author a saveable `selection_predicate.sql`, emit a `url_candidates.parquet` carrying the `(warc_filename, warc_record_offset, warc_record_length)` triples the rest of the pipeline consumes, estimate the downstream range-fetch byte budget and the distinct-host count (= Chapter 06 robots.txt fetch cardinality), and verify the predicate is reproducible across two consecutive runs. Based on Chapter 01, with consequence from Chapter 06. Stops before any WARC range-fetch — that is Exercise 01.
- [Lab 02 — Assemble and Validate the Chapter 07 Slice Manifest](lab-02-assemble-the-chapter-07-slice-manifest.md) — 75 min. For a fixture slice with 240 synthetic shards and six stub operators (`trafilatura_extract`, `fasttext_lang_id`, `kenlm_perplexity_tier`, `minhash_lsh_dedup`, `benchmark_decontaminate`, `pii_scrub`), compose the Chapter 07 slice manifest, a `shards/shard_index.parquet` binding every shard to its SHA-256 and sample count, and a `validate_slice_manifest.py` that enforces every Chapter 07 invariant — operator-chain continuity, acquire-evidence binding, shard discipline (count ≥ 100× data-parallel world size, sizes in 1–4 GB, sample-count uniformity within 5%), SHA-256 binding between manifest and shards, and the presence of Sigstore / SLSA fields — then break each invariant on purpose and watch the validator catch it. Based on Chapter 07, with operator-log shape from Chapter 02, acquire-evidence binding from Chapter 06, and per-operator instrumentation fields from Chapter 05.
